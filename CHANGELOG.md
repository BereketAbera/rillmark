# Changelog

## 0.2.0

- Three coordinated visual presets: Fieldnotes, Studio and Play. Set `data-rillmark-preset` and `data-rillmark-mode` on `html`; choose light, dark or system appearance independently. Every preset ships in both CSS entry points, with root inheritance for portals and reduced-motion support.
- Sixteen new components: Toggle, ToggleGroup, Collapsible, ContextMenu, HoverCard, NavigationMenu, ScrollArea, Command, NumberInput, TagInput, FileDropzone, Stepper, Timeline, Meter, Spinner and Kbd. The library now has 48 components with working examples and generated API documentation.
- Two complete browser-local workflows: a validated project brief with review/download and an activity inbox with filters, saved/read states, context actions and command search. Five examples now share the presets.
- A live preset explorer, persistent site controls, configuration copying and focused theme documentation for developers and agents.
- Runtime CSS variables for shape, type, shadow and motion. Existing Fieldnotes color tokens, imports and `.dark` usage remain supported; explicit appearance attributes take precedence over the legacy class.

## 0.1.0

Initial independent npm release: 32 components, Fieldnotes light/dark palettes, three complete examples, focused AI documentation and a bundled consuming skill.
